# Synthetic Auto Service Visits - R Documentation Demo

## Overview

This small R project shows how to organize and summarize **synthetic** auto-service visit records. It is a documentation exercise for BDA400, not a report about an actual shop or customers. All records were invented for demonstration.

## Project Files

| File | Purpose |
| --- | --- |
| `service_summary.R` | Creates synthetic visits and summarizes visit counts by service type. |
| `service_summary.Rmd` | Documents the script's purpose, inputs, process, outputs and limitations. |
| `Reflection.md` | Three reflections on documentation and AI assistance. |
| `Appendix_AI.md` | Prompt record, key AI suggestions and human validation checklist. |

## Requirements

- R 4.1 or later is recommended.
- No extra R packages are required; the script uses base R only.
- RStudio or Posit Cloud is recommended to preview the `.Rmd` document.
- To knit `.Rmd` to HTML, install `rmarkdown` and its required tools if they are not already installed.

## Installation

1. Install R from [CRAN](https://cran.r-project.org/).
2. Download or clone this repository.
3. Open the project folder in RStudio, or set the working directory to the folder in an R session.
4. Run `source("service_summary.R")`.

## Example Usage

```r
# Run from the project root.
source("service_summary.R")
print(service_counts)
```

The script builds a synthetic table in memory and creates a `service_counts` data frame. It does not read private files, download data or send information to a service.

## Inputs and Outputs

**Input:** An internally defined synthetic data frame with a visit ID and service type per record.

**Output:** `service_counts`, a data frame containing `service_type` and `visits` columns. Printed results are generated by R when the script runs; no numerical output has been copied from AI.

## Reproducibility and Limitations

The sample rows are fixed and the script uses no randomness. Results should be reproducible with the same code. The invented records are too small to support business forecasts or real-world conclusions.
